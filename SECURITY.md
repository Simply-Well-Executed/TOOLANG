# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, or exploit details in a public issue. Use GitHub's private vulnerability reporting or a private security advisory for this repository if that feature is enabled. If it is unavailable, contact the maintainer through a private channel already known to you. No dedicated security email address or response-time commitment is published.

When reporting an issue, include the affected file or component, the impact, and concise reproduction steps. Redact tokens, account details, local paths, and unrelated browser or screen data.

## Scope and support

The project is a local Windows overlay that reads the visible Chrome address bar when UI Automation is available and retrieves NHC feed/GIS data. Report security issues involving the project code, its local data handling, or its network and UI integration. No release support schedule or supported-version policy is currently defined.
